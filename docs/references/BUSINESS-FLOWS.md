## BUSINESS FLOWS
* PreToolUse:observe-runner.js (capture tool arguments and intent) -> PostToolUse:observe-runner.js (capture the output and result.)
* PreToolUse:governance-capture.js (Inspects tool_input before execution - blocks or flags dangerous commands like rm -rf / or credentials in arguments) -> PostToolUse:governance-capture.js (Inspects tool_output to check if secrets or sensitive data were returned by tools, or if elevated privileges (sudo, chmod) were executed)
* PreToolUse:pre-bash-dispatcher.js (enforce git push safety, block --no-verify, and manage tmux sessions) -> PostToolUse:post-bash-dispatcher.js (record command audit logs, created PR URLs and build completions)
* PostToolUse:post-edit-accumulator.js (write edit file histories to /tmp/ecc-edited-{sessionId}.txt ) -> Stop:stop-format-typecheck.js (Reads list once Groups by project / tsconfig - Runs Biome/Prettier + tsc once - Deletes temp file)
* Stop:cost-tracker.js (write token usage to ~/.claude/metrics/costs.jsonl) -> PostToolUse:ecc-metrics-bridge.js (read costs.jsonl and update atmomic bridge file) -> PostToolUse:ecc-context-monitor (if cost crosses 5, 10 , 50 $ injects a cost notice directly into Claude's prompt context.)
* PostToolUse:skill-run-tracker.js (When a skill succeeds, records outcome: 'success' to ~/.claude/state/skill-runs.jsonl.) -> Command:scripts/skills-health.js --dashboard (computes accurate success-to-failure ratios across all skills.) -> Command:evolve to fix decaying instructions
* PostToolUseFailure: skill-run-tracker.js (records outcome: 'failure'.) -> Command:scripts/skills-health.js --dashboard (computes accurate success-to-failure ratios across all skills.) -> Command:evolve to fix decaying instructions
* PreToolUse:mcp-health-check.js (checks server status before calling an MCP tool) -> PostToolUseFailure:mcp-health-check.js (catches MCP tool disconnects, marks the server degraded, and attempts reconnection before subsequent turns.)
* SessionStart:session-start.js ( Initializes session identifiers "CLAUDE_SESSION_ID, ECC_SESSION_ID", detects package managers, and loads context from previous sessions. ) -> PostToolUse:session-activity-tracker.js (Attaches the sessionId to every tool action, recording diffs and tool metrics to ~/.claude/metrics/tool-usage.jsonl) -> SessionEnd:session-end-marker.js (Commits final status markers once all tool loops and turns terminate - AND KILL OBSERVE-LOOP.sh)
* PostToolUse:ecc-context-monitor.js (When context drops below 35% or 25 %, it warns Claude and recommends wrapping up work or suggesting manual compaction.) -> PreCompact:pre-compact.js (When context compaction is triggered, pre-compact.js generates a structured LLM summary of the session transcript before memory is pruned, preserving key technical decisions for the next turn.)
